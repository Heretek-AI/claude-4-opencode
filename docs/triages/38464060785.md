### The Masked Defect

The prior triage in `38463641817.md` assumed model–task capability mismatch (zero tool use under prompt). However, upon adding exit code, stderr, and error event diagnostics to `attempt()`, the actual underlying failure was revealed in run 38467733828:

```json
{
  "type": "error",
  "error": {
    "type": "provider.quota",
    "message": "Go usage limit exceeded",
    "status": 429,
    "response": {
      "body": "{\"type\":\"error\",\"error\":{\"type\":\"GoUsageLimitError\",\"message\":\"Go usage limit exceeded\"},\"metadata\":{\"workspace\":\"wrk_01KY365GXABNQ8RQ2VSYT1PGEG\",\"limitName\":\"monthly\"}}"
    }
  }
}
```

**The OpenCode Go workspace quota (`wrk_01KY365GXABNQ8RQ2VSYT1PGEG`) had exceeded its monthly usage limit.**

Because `e2e/live/live.test.ts` did not log error events or process exit codes, and only inspected `events` for `tool_use`, the immediate HTTP 429 response was masked as `tools used: none`. The model was never actually invoked.
